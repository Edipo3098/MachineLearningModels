# Machine Learning Foundations

Learning exercises in Python covering neural networks implemented with NumPy and introductory data analysis with pandas.

## Exercises

| Exercise | What it covers |
| --- | --- |
| [XOR](XOR%20PROBLEM/solution.py) | A two-hidden-neuron network, sigmoid activation and manually implemented backpropagation |
| [Iris classification](IRIS%20PROBLEM/NeuralNet.ipynb) | Three input features from scikit-learn's Iris dataset, a ten-neuron hidden layer and three sigmoid outputs |
| [Introduction to pandas](Introduction%20to%20pandas/Introduction%20to%20pandas.ipynb) | CSV loading, missing values, selection, filtering, derived columns, grouping and plots |

These are educational implementations. Reported training error should not be interpreted as independently validated model accuracy.

## Environment

The exercises use Python 3, NumPy, pandas, Matplotlib and scikit-learn. Use JupyterLab to open the notebooks.

```bash
git clone https://github.com/Edipo3098/MachineLearningModels.git
cd MachineLearningModels
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell alternative:
# .venv\Scripts\Activate.ps1
python -m pip install numpy pandas matplotlib scikit-learn jupyterlab
jupyter lab
```

Dependency versions have not been pinned or validated in a clean environment.

To run the standalone XOR exercise:

```bash
python "XOR PROBLEM/solution.py"
```

The current training loop has no epoch limit and may take a long time depending on random initialization. A Matplotlib window is opened before the final predictions are printed.

For the pandas notebook, use `Introduction to pandas` as the working directory so that `dataset.csv` resolves. `salida.csv` is generated by the notebook. `FuelConsumption.csv` is currently empty and is not used by the reviewed notebook.

## Methodological limitations

- Iris preprocessing is performed before the train/test split. A revised evaluation should fit preprocessing on the training set only.
- Network initialization has no fixed random seed.
- Training loops need a maximum epoch count and explicit convergence reporting.
- The Iris evaluation reuses the accumulated training error; its final printed error is not a clean test-set metric.
- Classification accuracy, confusion matrices and baseline comparisons are not currently reported.
- The Iris plot labels use class names for axes; these should be feature names.
- The pandas notebook includes randomly generated illustrative gains and a followers ratio that needs zero-denominator handling.
